# 企业数据对标分析 Skill（enterprise_analyst）

一个面向**经营分析 / 数据资产定价 / 数字化转型**场景的 AI Agent Skill，基于 Trae 框架开发。

输入「细分行业 + 数据资源 + 业务痛点」，自动完成：**标杆企业匹配 → 多维度对标 → 数据资产三法估值 → 标杆案例拆解 → 可视化图表 → 可直接汇报的 HTML 报告**。

> 这是本项目唯一收录的自研 Skill。仓库中未收录 `visualization-expert`、`python-expert`、`work-report-writer` 等第三方开源 Skill（作者分别为 `awesome-llm-apps`、`ckchzh2022`，MIT / 开源库），避免混淆原创归属。

---

## 为什么做这个

企业做数据分析时经常遇到三个断层：

1. **不知道该和谁比**——同行业里业务模式、数据体量、发展阶段差异很大，随便找家头部企业对标结论没有参考价值；
2. **不知道自己的数据值多少钱**——数据资产入表、交易、融资都需要一个可解释的估值口径；
3. **分析做完了落不了地**——图表一堆，但没有差距根因、没有分阶段实施路径。

这个 Skill 把这三件事串成一条流水线：先用加权相似度模型筛出真正可对标的标杆企业，再用成本法/收益法/市场法给出估值区间，最后输出差距根因 + 短中长期实施计划。

## 核心能力

| 能力 | 说明 |
|---|---|
| 细分行业识别 | 粗略行业自动给出细分选项，确认后再分析（内置 170+ 细分行业知识库） |
| 标杆企业匹配 | Top 5–10，给出相似度（1 位小数）、匹配维度、可借鉴等级 |
| 多维度对标 | 财务、运营、效率、数据能力等指标逐项对比 |
| 数据资产三法估值 | 成本法 + 收益法 + 市场法，展开完整计算过程 |
| 案例深度拆解 | 标杆企业的落地路径、关键动作、数据成果 |
| 交互式图表 | 分组柱状、雷达、双轴、偏差、趋势、气泡、热力（Plotly 生成，随数据变化） |
| HTML 报告 | 结构完整、可直接用于管理层汇报与立项 |

## 方法论

### 1. 相似度加权模型

```
相似度 = 行业匹配 × 30% + 业务模式 × 25% + 数据资产结构 × 20%
       + 企业规模 × 15% + 发展阶段 × 10%
```

| 分值 | 判定 | 处理 |
|---|---|---|
| 90–100 | 极高相似度 | 直接对标 |
| 80–89 | 高相似度 | 优先借鉴 |
| 70–79 | 中等相似度 | 部分参考 |
| < 70 | 低相似度 | 不推荐 |

### 2. 数据资产三法估值

- **成本法**：`(采集 + 存储 + 处理 + 治理成本) × 积累年限 × 成新率` → 重置成本价值
- **收益法**：未来 3 年内部收益 + 外部收益，按折现率折算 → `NPV × 成功概率`
- **市场法**：数据条数、质量等级、客户数、转化率、稀缺溢价 → 市场可交易价值

## 使用方式

把 `SKILL.md` 及 `assets/`、`reference/`、`scripts/` 放入 Trae 的 skills 目录后，直接输入以下任一指令即可触发：

```
企业数据对标分析
企业数据对标
企业数据资产估值
帮我做行业对标分析
```

### 输入规范

**必填**
1. 企业所属细分行业（例：新能源汽车—纯电动乘用车）
2. 数据资源清单（表名、字段、量级、时间跨度）
3. 核心业务痛点 / 现状指标 / 目标值

**选填**
- 对标范围（上市公司 / 头部 / 同规模 / 国内 / 海外）
- 时间范围（近 1 / 3 / 5 年）
- 重点关注指标
- 企业规模、营收、人员、产能
